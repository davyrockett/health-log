Syncing with

Turn off sync on this device? Your data stays here, but it stops matching your other devices. You'll need the access key to turn it back on.

Your data is kept in a private GitHub project, and every device you connect stays matched with it. Set it up once on each device.

How to get an access key

Easiest: add this project to your Z4 Log key, then paste that same key here.

  1. On github.com, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Open Z4 Log sync, then Edit.
  3. Under Repository access, add health-log-data. Save.

Or make a separate key: Generate new token, name it “Health Log sync”, choose Only select repositories → health-log-data, and set Repository permissions → Contents to Read and write.
